## 一、文案问题清单（逐条：位置 → 原文 → 诊断 → 改写成稿）

### A. 全局外壳（index.html / app.js）

**A1｜P0｜index.html:85**
- 原文：`模型 LATTICE-Sci-1 · 温度 0.2 · 所有数值可追溯`
- 诊断：平台实际是本地规则引擎，虚构了一个"模型名+温度"的 LLM 外观。用户看不懂"温度 0.2"，评委追问时会变成诚信问题。
- 改写：`本地规则引擎 · 每一步计算都可点开查看依据`

**A2｜P1｜index.html:81、205（app.js）**
- 原文：`Agent 推理轨迹`／空态 `等待环节启动`／`本环节的推理链路会在此实时展开：输入 → 约束 → 计算 → 判定`
- 诊断："Agent""推理链路"是开发者黑话；且默认占据右栏 1/4 屏宽，是"杂乱"感的主要来源之一。
- 改写：面板标题改为 `计算过程`，空态改为：`运行任一环节后，这里会逐步显示它做了什么、用了哪些原文数据。`并默认收起为一条可展开的窄条。

**A3｜P1｜index.html:44-46**
- 原文：`预测值 · 待真实数据矫正`（title 写"预测值由机理约束模型实时计算…"）
- 诊断："机理约束模型"无解释；徽章常驻顶栏却不说明"哪里是预测值"。
- 改写：`曲线为文献推算值，非实测`（title：`环节 04/05 的曲线由原文的变量水平与最优值推算；在环节 07 填入你的实测数据后会自动修正`）

**A4｜P1｜index.html:55-59**
- 原文：`算力 0 / 2500`
- 诊断：没有任何解释这是什么、用完会怎样。用户会以为要付费。
- 改写：`演示额度 0 / 2500`（title：`赛事演示用计数器，仅统计环节运行次数，不影响任何功能`）

**A5｜P2｜index.html:92-93**
- 原文：`RUN LOG`＋硬编码 `job-2609-0930`
- 诊断：假 job 编号常驻，像调试残留物。
- 改写：`运行记录`，去掉固定 job id，或改为真实时间戳。

**A6｜P1｜app.js:10-19（环节副标题）**
- 原文：01 `上传 → 结构化 → 方法与原理分析`；03 `配比确定 → 线上原理 → 线下风险与成功率`；09 `中英双语 / 口吻模仿 / 降 AI 率`
- 诊断："结构化""线上原理/线下""口吻模仿"均非用户语言；"降 AI 率"措辞在评审场合易引起误解。
- 改写：01 `导入论文，自动读出原料、变量与指标`；03 `确定用量与水平，检查试剂安全`；09 `检测并修改文稿的 AI 写作痕迹`

**A7｜P0｜app.js:386**
- 原文（行为）：`runStage` 会把之前所有未完成的环节静默标为 done。
- 诊断：左栏环节状态瞬间从"未做"变"已完成"，用户对状态彻底失去信任（"很多东西都是错误的"的佐证之一）。
- 改写（行为建议+文案）：不静默置 done；跳过的环节标为 `已跳过（未运行）`，hover 显示 `该环节未实际运行，结果为占位，点此补运行`。

**A8｜P2｜app.js:583-584（启动日志）**
- 原文：`这是一个面向材料学科全部方向的平台：上传任意材料类论文（DOCX / TXT / PDF 或粘贴正文），平台只抽取并分析你导入的这篇文献。未上传时，可在环节 01 选择内置示例文档体验流程。`（75+ 字一句）
- 改写：`上传一篇论文（DOCX / TXT / PDF，或直接粘贴正文），平台只分析这一篇。想先看看效果？到环节 01 选一篇示例文档。`

### B. 环节 01（views2-stages.js）——"杂乱"重灾区

**B1｜P2｜views2-stages.js:237（环节 01 副标题）**
- 原文：`本平台面向材料学科的全部方向。导入任意材料类论文（DOCX / TXT / PDF 或粘贴正文），平台会抽取其中真实出现的内容：原料与试剂、仪器设备、测试标准、工艺步骤、变量与水平、可测指标、配比与参考文献。原文没有的项目一律标为「未报告」，不会被补全，也不会进入后续分析。`（约 130 字一段）
- 诊断：首屏第一段就抛 8 个并列名词 + 一条免责声明，用户没耐心读完。
- 改写：`上传一篇论文，平台自动读出其中的原料、仪器、实验变量和性能指标。读不出来的项会如实标注，绝不编造。`

**B2｜P2｜views2-stages.js:243-255（10 张方向卡片铺满首屏）**
- 原文：`第 1 步 · 选择材料方向`（10 卡）+ body 引导句 `选择方向后，平台会按该方向的术语表增强识别（力学 / 热学 / 电学 / 光学 / 磁学 / 化学 / 加工 / 结构 / 生物 / 吸附…），并据此解释你的结果。不选也可以，平台会自动识别。`
- 诊断：用户还没导入任何东西，先被要求做一个他不理解的决策——这正是"一开始就应该只是导入文献"（用户原话 3）的反面。
- 改写：默认折叠为一行：`材料方向：自动识别 ▾（选错也没关系，仅影响术语识别精度）`，点击才展开 10 卡。

**B3｜P1｜views2-stages.js:306**
- 原文：`抽取置信度 40 / 100`，脚注 `由各字段抽取数量加权`
- 诊断：①"置信度"未解释；② 脚注说的是"怎么算的"而不是"对你意味着什么"；③ 40 分看起来像平台打分的失败，但没有任何行动指引。这是事故现场的直接视觉证据。
- 改写：`解析完整度 40 / 100 —— 这篇文献的多数字段没能读出来`，低于 60 时直接在数值下附一句：`这通常不是论文的问题，而是文件解析不完整。建议：① 换用「粘贴正文」重新导入；② 查看右侧「解析自检」里的具体原因。`

**B4｜P1｜views2-stages.js:317-321、339（来源标注体系）**
- 原文：chips `原文自带 / 正文识别 / 取自文件名 / 自动推断 / 自动归纳 / 未获得` + 339 行 note 的长解释
- 诊断：6 种状态对一次只关心"这能不能信"的用户太多；解释写在 panel note 里，字小、位置靠下。
- 改写：收敛为 3 档：`原文内容`（绿）/ `平台推断，请核对`（黄）/ `未找到`（灰）。每个 chip 加 hover 一句话：`平台按规则从正文/文件名推断，原文中并没有这个字段`。

**B5｜P1｜views2-stages.js:329**
- 原文：`English title`
- 诊断：中文界面里的英文标签。
- 改写：`英文题名`

**B6｜P1｜views2-stages.js:334**
- 原文：按钮 `换一段 1/6`
- 诊断：不解释"换什么、为什么要换"。
- 改写：`这段不像摘要？换一段试试（1/6）`，并在摘要块上方加一句：`原文没有 Abstract 字段，以下是从正文推断的首段，由你确认哪段是摘要。`

**B7｜P1｜views2-stages.js:365、371**
- 原文：面板 `可测指标（按性能族归类）`，note `归类依据是材料学科的性能族词表（力学 / 热学 / …）。归类只影响解释口径，不改变抽取到的内容。`
- 诊断："性能族""解释口径"是自造术语。
- 改写：标题 `指标清单（已按类别分组）`；note：`类别只用于分组展示，不影响抽到的原始内容。`

**B8｜P0｜views2-stages.js:375-377 + 449-452（"未报告"满屏）**
- 原文：缺失项面板 `原文缺失项（后续不再臆造）`，每行右侧 chip `未报告`；仪器型号列 `<span style="color:var(--sig)">未报告</span>`
- 诊断：这是用户看到"一片未报告"的直接来源。问题不在"未报告"三个字，而在**它混淆了两种完全不同的情况**：(a) 原文真的没写；(b) 解析器没抽出来（本次事故）。两种都显示"未报告"，用户只能得出"平台坏了"或"论文很烂"的错误结论。
- 改写：拆成两种状态——
  - 原文确实没写：`原文未写明`（灰）＋hover：`这篇论文没有给出该项内容，这不影响已抽到的其他内容。`
  - 解析失败：`未能读出`（黄）＋hover：`这通常是因为 PDF 文字层异常。建议改用「粘贴正文」重新导入，或查看「解析自检」。`
  - 并在缺失项面板标题改为：`没能读到的内容（及原因）`。

**B9｜P1｜views2-stages.js:389、397、408、429、446（noneNote 系列）**
- 原文示例：`原文中未识别到"名称 + 规格 + 供应"格式的原料/试剂描述。`（389）
- 诊断：把匹配规则（"名称+规格+供应"格式）暴露给用户，像报错日志。
- 改写：`没有识别到原料/试剂清单。可能是原文以表格形式给出（暂不支持表格解析），也可能是文字未完整读出。你可以：① 用「粘贴正文」把"材料与方法"一节贴进来重试；② 在环节 03 手动补充。`
（统一模板见第四节"空状态专章"。）

**B10｜P2｜views2-stages.js:268-289（"示例文档"与"已核验文献（仅题录）"两个并排面板）**
- 诊断：用户分不清两类，也不知道该点哪个；两个面板共 7 行说明文字。
- 改写：合并为一个面板 `先看看效果（可选）`，分两组列出，组头一句话：`示例文档——平台虚构，用于演示`／`真实文献——只有题录，需自行上传全文`。每组 note 删掉，信息并进组头。

**B11｜P2｜views2-stages.js:293-299（"还没有载入论文"面板）**

- 改写：未载入状态下**只保留**该面板（含三个动作按钮）+ 折叠的方向选择，其余全部后置（见第三节分层模板）。

## 二、中文化规范（英文文献抽取结果的呈现规则）

### 2.1 三档处理规则

**【必须译为中文】**——以下类别以中文为第一呈现语言：
研究对象与材料通名（cotton fabric→棉织物）、变量名与水平（concentration→浓度；水平值保留数字与单位原样）、指标名（tensile strength→拉伸强度）、工序动词（annealed→退火）、章节标题（Experimental→实验部分）、摘要与关键词（整段翻译并标注`由平台翻译`）、缺失项说明、表格列名、图注说明文字。

**【保留原文并加注】**——以下类别不译，首次出现加中文注：
化学式（AgNO₃、CMC 之后注"羧甲基壳聚糖"）、仪器型号（S-4800、Spectrum Two）、标准编号（GB/T 20944、ASTM E2149）、期刊名、人名/机构名、DOI。
**常用缩写**（SEM / XRD / FTIR / TEM / XPS / BET / EIS / TGA / DSC / UV-Vis / NMR / GHS / SDS / LOD）保留缩写，首次出现展开：`扫描电子显微镜（SEM）`，之后用 SEM。

**【中英并存格式】**——推荐 **「中文（English）」**，理由：① 读者是中文材料专业科研人员，中文为主读速最快；② 保留英文原词保证可回查原文、可检索；③ 与"每条附原文依据"的产品原则一致——英文原词即最小单位的原文依据。摘要、关键词等整段内容则相反：中文译文为主，可折叠查看英文原文。

## 三、分级披露的文案结构模板（导入 → 解析概览 → 明细）

总原则：入口层 ≤2 个动作；主标题 ≤12 字；说明只写"对你意味着什么"，不写"我们怎么实现的"；下一层永远给"回去修改"的出口。

### 第 1 层 · 导入（默认视图，未载入论文时只有这一层）
- 主标题：`从一篇论文开始`（7 字）
- 一句说明：`上传或粘贴论文全文，平台只分析这一篇，读不出的地方会如实告诉你。`
- 动作（仅 2 个）：`[上传文件]` `[粘贴正文]`；下方一行小字：`没有文献？选一篇示例看看 →`
- 空状态（未导入）：`还没有论文。上传 DOCX / TXT / PDF，或直接粘贴正文。文件只在你本机解析，不会上传。`
- 错误状态（解析失败）：`这份文件读不出文字——可能是扫描件或加密文档。你可以：① 在 Word 里全选复制后点「粘贴正文」；② 换一份有文字层的文件。`
- 下一步引导：`解析完成，来看看读出了什么 →`（自动进入第 2 层）

### 第 2 层 · 解析概览（导入后默认停在这里）
- 主标题：`读出了这些内容`（7 字）
- 一句说明：`绿色是读到的，黄色是推断的，灰色是没读到的。点任何一项可展开原文依据。`
- 内容：1 行 4 个数字卡（原料 N 种 · 仪器 N 台 · 变量 N 个 · 指标 N 项）+ 完整度评分（见 B3 改写）+ 「解析自检」折叠条。
- 空状态（啥也没抽到）：`没能从这篇论文读出有效内容。这通常是文件解析问题，不是论文问题。① 改用「粘贴正文」重新导入（最可靠）；② 查看解析自检了解原因。`
- 下一步引导：`确认无误？进入研究定位 →`／`内容不对？重新导入`

### 第 3 层 · 明细（点击展开，即现有 8 张表面板）
- 主标题：沿用表名但去术语化（`原料与试剂`／`仪器设备`／`变量与水平`／`指标清单`…）
- 一句说明/表：每张表只配一句"这是什么 + 从哪来的"，如：`论文里出现的全部原料，点击任一行看它出自原文哪句话。`
- 空状态：见第四节模板（原因 + 行动）。
- 下一步引导：每屏底部固定一条：`继续 → 环节 02 研究定位`

## 四、空状态与错误状态专章

### 4.1 规范（四条铁律）
1. **说清原因，且区分责任**：是"原文没写"还是"平台没读出来"，必须用两套文案（见 B8），永不混用"未报告"。
2. **必须给一个可执行动作**：每个空状态至少 1 个按钮或明确路径（粘贴正文 / 手动补充 / 跳过继续）。没有出路的状态不配出现。
3. **禁用实现细节**：不出现"格式""正则""文字层""ToUnicode"等词，它们只能进「解析自检」折叠区。
4. **结构固定**：`发生了什么 → 为什么 → 你现在能做什么`，三句以内。

### 4.2 成稿示例（5 条）
1. **扫描件 PDF**：`这份 PDF 里没有可选中的文字（是图片扫描件），平台无法分析图片内容。你可以：① 在 Word/WPS 里全选复制正文，用「粘贴正文」导入；② 换一份文字版 PDF。`
2. **英文文献抽取为空（本次事故场景）**：`这篇英文论文的文字没能正确还原（PDF 排版导致单词粘连），所以大部分字段读不出来。最可靠的解决办法：把正文复制后用「粘贴正文」重新导入。`
3. **综述类文献**：`这是一篇综述，本身没有实验变量和步骤——这是文体特点，不是解析失败。后续环节将按"技术概念路线"为你展示这篇综述的内容地图。`
4. **仪器型号为空**：`原文没有写明这台仪器的型号。写论文或复现实验时建议补上型号，否则他人无法重现测试条件。`（状态：`原文未写明`，灰）
5. **未识别到变量**：`没有找到"同一参数出现多个取值"的实验变量。可能：① 该文不是控制变量式研究（如综述）；② 变量在表格里，暂不支持表格解析。你可以用「粘贴正文」把实验部分贴进来重试，或跳过变量分析继续。`
