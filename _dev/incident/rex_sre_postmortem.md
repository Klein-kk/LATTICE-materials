## 1. SEV 评级：**SEV2（主要功能失效，高端）**

| 判据 | 事实 | 结论 |
|---|---|---|
| 功能可用性 | 平台核心承诺「导入什么就分析什么」对英文文献**完全不成立**：摘要长度 0、原料/试剂 0、变量与水平 0、章节仅切出 1 段、参考文献 18/≥30、置信度 40/100（brief.md §三） | 主要功能失效 |
| 影响用户比例 | 平台目标语料是材料类文献，用户实际文献库 **363 篇 PDF 全部为英文**（`E:\生物材料文献（假期）\C组文献\C组文献\`，按文件名判读，抽查前 30 篇均为英文期刊论文） | 接近全量用户路径 |
| 是否有绕过方案 | **有部分绕过**：环节 01 支持「粘贴正文」（`pdftext.js` fromFile 错误提示中已有该引导），粘贴路径不经过 PDF 解析器 | 不满足 SEV1「服务宕机无绕过」 |
| 是否阻塞对外演示 | 是（brief.md §六：直接阻塞赛事演示方向二） | 加重 |

**结论**：核心功能对绝大多数真实输入失效 → SEV2。不定 SEV1 的理由：存在「粘贴正文」绕过（但用户不知晓、需手工操作，体验严重受损）；不定 SEV3 的理由：失效的是产品主路径而非次要功能，且阻塞对外演示、信任度持续消耗。**按 SEV2 高端处理：15 分钟内响应，当日修复。**

## 2. 影响面量化

**失效路径（单点故障级联）**：`pdftext.js` 抽出无空格文本 → `extract.js` 分词/词典匹配全失效 → 摘要 0 / 原料 0 / 变量 0 / 章节 1 段 → 界面回填 78+ 处「未报告 / 未识别」兜底文案（`assets/js/` 下 9 个视图文件命中统计）→ 用户感知「错误」「看不懂」「那么多那么杂乱」（brief.md §一 用户原话 1–2）。

**实测数据（brief.md §三 + SRE 独立复核）**：

| 指标 | 实测 | 复核方式 |
|---|---|---|
| 抽出非空白字符 | 27,702 | 探针复测一致 |
| **空格数 / 空格占比** | **0 / 0.00%**（总字符 27,863，换行 161） | SRE 探针实测；正常英文正文空格占比约 15%–20% |
| 最长无空格片段 | **817 字符** | SRE 探针实测 |
| 摘要 / 原料 / 变量 | 0 / 0 / 0（原文确有 AgNO₃、CMC、L-甲硫氨酸、柠檬酸、NaOH） | brief 实测表 |
| 章节切分 | 1 段（期望 ≥5） | brief 实测表 |

**受影响文档类型**：采用 **TJ 数组负 kern 值 / Td·Tm 水平位移**实现词间空格的 PDF —— Springer、Elsevier 等现代期刊排版（含本次样本 2019 Cellulose）。**反向证据**：上一轮验证通过的 2000 Nature、2001 Trends 属老排版（直接绘制空格字形），恰好不触发缺陷 —— 这解释了「修过英文却仍然在英文上翻车」（`_dev/mem_append.md` ①–⑤）。中文路径不受影响（中文不依赖空格分词）。

**受影响用户路径**：PDF 拖拽导入（英文）= 平台第一入口；用户文献库 100% 英文 ⇒ 真实场景下英文路径失效 ≈ 平台主路径失效。

## 6. 5 Why 根因链（无责复盘）

1. **为什么英文论文分析不出结果？** → 摘要、原料、变量抽取全为 0，因为英文分词失效、词典（多词短语）匹配不到。
2. **为什么分词失效？** → PDF 抽出的 27,702 字符**全文 0 空格**，单词黏成最长 817 字符的连续串（SRE 探针实测）。
3. **为什么抽出文本无空格？** → `pdftext.js walk()` 只还原文本显示算子中的字形：TJ 数组里的 kern 调整值被忽略、Td/Tm 水平位移不转空格、`Tw`/`Tm` 算子未实现（pdftext.js L529–571）。本次样本（Springer 排版）正用这种「定位空白」。
4. **为什么这个缺陷能上线？** → 测试语料盲区 + 断言失效：smoke4.js 断言样本为 4 篇自造中文样本；英文真实 PDF 仅覆盖老排版综述（2000 Nature/2001 Trends，用真·空格字形，恰好绕过缺陷）；可读性断言用子串匹配，无空格文本也能通过。
5. **为什么测试语料和断言会偏？** → **流程/机制层根因**：质量保障以「自造样本 + 当期 bug 打地鼠」为中心——没有真实文献语料库（按出版社 × 年代 × 版式 × 语言分层采样）、没有抽取质量的结构性指标断言（空格率/词长分布/抽取量下限）、历次误抽取修复（SEM/Acros/deGlue）均无回归样本沉淀。缺陷不是「没测英文」，而是**没有任何机制保证「真实用户输入的分布」被测试覆盖**。

**预防措施（可检查、可执行）**：

| # | 措施 | 验收标准 | 负责 |
|---|---|---|---|
| P1 | 建立真实文献回归语料库：出版社（Springer/Elsevier/Wiley/ACS/RSC）× 版式（单/双栏）× 年代 × 语言分层，≥20 篇，含 ≥5 篇英文研究型论文 | 语料清单入库，smoke 必跑、不再依赖可选 PDFDIR | Tessa |
| P2 | 抽取质量结构性断言：英文正文空格占比 12%–20%、最长无空格片段 <50、平均词长 4–8、摘要/原料/变量/章节数量下限 | 任一指标越界即构建失败 | Tessa |
| P3 | 可读性断言由子串匹配改整词匹配（`\b`） | 断言对无空格文本必失败 | Tessa |
| P4 | 每次误抽取/解析修复必须随附回归样本，禁止无样本修复合入 | PR 检查清单项 | Cody + Tessa |
| P5 | 发布前用用户真实文献库随机抽 10 篇走查（当前 C 组 363 篇全英文，即是最佳样本池） | 走查记录附发布说明 | Rex |
| P6 | 「粘贴正文」绕过路径显性化（导入失败/低置信度时自动引导） | 置信度 <60 时界面出现引导 | Cody + Archi |
