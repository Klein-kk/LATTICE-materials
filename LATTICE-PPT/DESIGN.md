# LATTICE 平台介绍 PPT · 设计稿（DESIGN）

> 风格路由结论：**产品/营销类通用设计**（不命中学术/咨询/红金任一预设分支），走通用设计原则原创。

## 1. 画布与全局母版（A/B/C 三区，1280×720）

| 母版区 | 位置 | 高度 | 规则 |
|---|---|---|---|
| A · 标题块 | 0–120px | 120px | 主标题 34–40px bold，左侧深青竖条 + 标题；右侧统一 L3 晶格角标（≤64×64） |
| B · 内容区 | 120–660px | 540px | 一切正文/图/卡；封面·章节·结束页可自定义 |
| C · 页脚条 | 660–720px | 60px | 左侧「LATTICE · 材料学科科研自动化平台」14px 灰字 + 右侧页码 `NN / 14` 14px |

- 页面 padding：上下 20px、左右 64px（封面/结束页左右可放宽）。
- 内容页 A/B/C 三区严格一致；封面(P1)/结束(P14) 用全幅图自定义版式（保留右下页码）。

## 2. 颜色系统（4 hex）

| 角色 | hex | 用途 |
|---|---|---|
| 主色 深青 | `#0E3B39` | 标题块底色、大色块、竖条、深色背景 |
| 辅色 浅青底 | `#E6F4F1` | 卡片底、图表第二系列、分隔带 |
| 强调 青 | `#22B8A6` | 巨型数字、焦点描边、CTA、核心数据标注（仅焦点出现） |
| 文本/中性 | `#0F1C1B`（主文字）`#5B6B6A`（次级灰） | 正文、页脚、边框 |

**面积分配**：常规页 主色≤60% / 辅色≤30% / 强调≤10%；Hero 页强调色可到 15–20%。禁止全篇比例雷同：P4、P11 强调色爆发（约 18–20%），P2/P12 主色偏重，其余克制。

**渐变与半透明**：标题块 `linear-gradient(135deg,#0E3B39 0%,#16544F 100%)`；卡片浅青 `rgba(34,184,166,0.08)` 叠底；封面/结束全幅图叠 `rgba(8,28,27,0.55)` 蒙版保证白字可读；卡片 `boxShadow:0 4px 20px rgba(0,0,0,0.08)`。

## 4. 信息密度门禁

- 常规内容页：正文≥180 字 / 主视觉占 B 区≥30% / 留白≤35%。
- 卡片填充率≥85%；高≥380px 卡正文≥100 字；尾部引文条 `marginTop:'auto'` 钉底；兄弟卡三段 y 轴等高对齐（差≤16px）。
- Hero 页允许留白 35–42%，围绕核心元素聚焦。

## 5. 配图系统（SVG 兜底方案）

> **环境约束**：当前环境 ImageGen 不可用，依技能规则改用 **SVG 兜底**。全部 L1/L2 主视觉以 `<SVG>` 内联矢量绘制，统一视觉语言——深青 `#0E3B39` 底 + 青 `#22B8A6` 辉光 + 几何/科学可视化（晶格网络、球棍晶体、知识图谱、实验室意象）。风格统一，不混用位图。

| 用途 | 实现 | 位置 | 说明 |
|---|---|---|---|
| 封面主视觉 | 内联 SVG（晶格网络 + 辉光） | P1 全幅背景 | 抽象分子晶格，青色节点连线 |
| 3D 晶体结构 | 内联 SVG（球棍模型） | P7 左大图 | CPK 配色原子 + 键 + 透视 |
| 高校实验室场景 | 内联 SVG（等距实验室意象） | P8 上大图 | 台面/烧瓶/数据流屏 抽象 |
| 文献数据网络 | 内联 SVG（知识图谱） | P10 左大图 | 节点 + 连线 + 光点 |
| 结束主视觉 | 内联 SVG（晶格生长） | P14 全幅背景 | 向上汇聚成晶格，希望感 |
| L3 晶格角标 | 内联 SVG | 全篇 A 区右上 | ≤64×64 小晶格 mark |

SVG 视觉统一规范：背景 `linear-gradient(135deg,#0E3B39 0%,#0A2A28 100%)`；节点/连线用 `#22B8A6` 与 `rgba(34,184,166,0.35)`；辉光用 `filter blur` 或低透明大圆；线条 `strokeWidth 1.5–2`，圆 `r 6–14`。

## 7. 配图清单（生图 prompt 摘要）

全部统一风格：`3D scientific visualization, deep teal #0E3B39 background, glowing cyan #22B8A6 accents, premium studio lighting, clean high-tech, no text, no logo`.

1. `cover_hero.png`：抽象分子晶格网络悬浮于深青空间，青色辉光节点连线，棚拍质感，电影感。
2. `crystal_3d.png`：球棍模型晶体结构（CPK 配色原子+键），悬浮旋转感，青色辉光，深色背景。
3. `scenario_lab.png`：等距 3D 现代材料实验室（台面仪器/烧瓶/屏幕数据流），冷调科技感。
4. `scenario_data.png`：3D 文献知识图谱网络（节点+连线+光点），青色流动，深青底。
5. `ending_hero.png`：3D 抽象材料/数据流汇聚成晶格，向上生长，希望感，深青底青辉。
