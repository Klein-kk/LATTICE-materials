# LATTICE 平台介绍 PPT · 叙事稿（STORY）

## ① 用户意图对齐

- **目标受众**：潜在采用方——高校材料学科研团队、企业新材料研发中心、科研院所与文献情报部门；也可用于立项汇报 / 产品招商路演。
- **核心目标**：让观众记住"LATTICE 是把一篇材料论文自动跑成一篇可投稿成果的十环节流水线平台"，并相信它能**大幅压缩科研周期、零门槛部署、且绝不强造数据**。
- **PPT 长度**：14 页（Hero 页 4 页：封面 / 平台总览 / 价值冲击 / 结束页）。
- **视觉调性**：科技未来 · 高级克制 · 材料冷调 · 数据冲击。深青主色 `#0E3B39` + 青色强调 `#22B8A6` + 近白底 `#F5F8F8`。
- **内容边界**：
  - 必讲：十环节流水线、真实论文锚定抽取、3D 科研绘图与 SCI 配图规范、三大应用场景、被夸大的价值/效益、零部署零依赖技术底座。
  - 不讲：抽取引擎具体正则实现、GHS 词典逐条、PDF 解码算法细节（仅作"技术硬实力"一笔带过）。
  - 禁碰：伪造数据、虚构客户案例、夸大到明显虚假的承诺（夸张但保持"可理解的可信区间"）。

## ② 页面布局骨架

- **页面总数**：14 页，分 4 章：

### 文案要点（逐页）

**P1 封面**：主标「LATTICE」+ 副标「材料学科科研自动化平台」+ 一句话价值「让每一篇文献，自动长成一篇可投稿的成果」。

**P2 目录**：四章——01 为什么需要 LATTICE / 02 平台与核心能力 / 03 三大应用场景 / 04 价值与行动。

**P3 痛点（非对称双栏）**：左"科研的现实"——周期长（一篇论文动辄数月）、重复劳动（抄录数据、画图表）、学术不端风险（凭空补数）、部署门槛高（服务器/环境/联网）。右"代价"——时间成本、人力成本、发表不确定性。

**P4 平台总览（巨型数字）**：4 个锚点数字——「10」十环节流水线 / 「10」材料大方向 / 「250+」中英双语指标词表 / 「0」依赖·零部署。一句话定位。

**P5 十环节流水线（上流程图+下卡片）**：SVG 横向流程 01→10，下方 3 张卡概括"导入解析 / 撰写评审 / 绘图配图"三段。

**P6 智能抽取（非对称双栏）**：左讲"真实论文锚定"——每条结论附原文依据、缺项标未报告、绝不臆造；右列能力清单（原料/仪器/工艺/变量/指标/参考文献）。

**P7 3D 科研绘图（左大图+右文字）**：3D 响应面、晶胞球棍、层状界面；期刊配色板（Okabe-Ito 色盲安全）；SCI 配图手册按指标族自动匹配图型。

**P8 高校科研（上大图+下卡片）**：场景——研究生/课题组把文献一键导入，自动出实验指导书与初稿；下方 2 卡：提速、规范、可复现。

**P9 企业研发（非对称双栏）**：场景——新材料企业研发知识沉淀、配方与工艺快速结构化、保密（数据不出本机）。

**P10 综述情报（左大图+右文字）**：场景——综述/展望类文献自动提取概念路线图、对比矩阵、年份演进；从论文自身提取术语，不预设词池。

**P11 价值冲击（居中巨型数字）**：3 个被夸大的价值锚点——「10×」科研效率跃升 / 「85%」论文周期压缩 / 「100%」原文可追溯·零编造。配一句金句。

**P12 技术底座（左标题+右内容）**：纯静态·零构建·零第三方运行时依赖；PDF v3 解析器（4017 乱码→54586 字符）；本地 132 条真实文献库；双击 index.html 即跑。

**P13 为什么选我们（N 卡片横排）**：3 卡——真实锚定不编造 / 零部署零门槛 / 全学科覆盖。

**P14 结束页**：金句「把科研的重复劳动，交给 LATTICE。」+ 行动号召「现在就双击 index.html，开启你的十环节流水线。」

> 注：价值/效益类表述为营销夸张口径，用于突出平台定位；落地以平台实际能力为准。
