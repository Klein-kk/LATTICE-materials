# LATTICE · 材料学科科研自动化平台

面向**材料学科全部方向**的十环节科研流水线 Web 应用。

两条硬原则：
1. **不预设研究方向** —— 平台不绑定任何具体课题，由你导入的论文定义课题。
2. **只分析原文有的内容** —— 抽取引擎只输出论文中真实出现的东西，抽不到的标「原文未报告」，绝不补全、绝不臆造。

> 纯静态、零构建、零第三方运行时依赖。双击 `index.html` 即可运行，也可 `python -m http.server`。
>
> 视觉为**中性冷调 · 高级简约**：近白纸面 `#F6F7F8` + 纯白面板 + 发丝线 `#E4E6E9`，单一深青强调 `#16544F`，语义色一并去饱和；表格数据用 IBM Plex Mono 等宽对齐，标题用 Newsreader 衬线营造期刊感。

## 1. 面向所有材料专业

### 10 个材料方向（可指定，也可自动识别）
金属材料 · 无机非金属材料 · 高分子与复合材料 · 能源与储能材料 · 电子与光电材料 ·
生物医用材料 · 纤维与纺织材料 · 建筑材料 · 化工与催化材料 · 环境功能材料

选择方向后，平台按该方向的术语表增强识别；不选则由引擎自动判断。

### 12 个性能族 · 250 项指标词表（中英双语）
力学性能 / 热学性能 / 电学与电化学 / 光学性能 / 磁学性能 / 化学与耐候 /
加工与成型 / 结构与成分 / 生物与安全 / **传感与分析性能** / 吸附与分离 / 声学与其他

> 「传感与分析性能」独立成族：`sensitivity / selectivity / LOD / response time / stability / biofouling …` 原先被塞进「生物与安全」，导致生物传感器类论文（如 *Nature Reviews Endocrinology* 的可穿戴传感器综述）的指标被系统性地归错类别。中文侧同样独立，并把 `选择性` 保留在「吸附与分离」以免抢占吸附类论文的术语。

抽取到的每个指标都会被自动归入某个性能族，用于后续的解释口径（**归类只影响解释，不改变抽取到的内容**）。

内置的仪器词表、试剂词表、材料名词表、工艺动词表（覆盖熔炼铸造、热处理、球磨烧结、
溶胶-凝胶、静电纺丝、磁控溅射、蒸镀、成型固化、养护切割、电池装配等）同样服务于"能否识别"，
不参与内容生成。

## 2. 十环节

| # | 环节 | 说明 |
|---|---|---|
| 01 | 文献导入与解析 | 上传 DOCX / TXT / MD / PDF，或粘贴正文；抽取原料试剂、仪器设备、测试标准、工艺步骤、变量与水平、可测指标、配比、参考文献 —— **每条附原文依据**，缺失项单独列清单 |
| 02 | 文献拓展与研究定位 | 研究对象 = 原文的原料与工序；变量 = 原文出现两个以上取值的参数；检索式由所选对象拼接并给出 OpenAlex / Crossref / Scholar / 知网等真实链接；研究空白 = 变量 × 指标 − 原文已建立的关系 |
| 03 | 变量设计与安全评估 | 水平按钮就是原文出现过的取值；配方原样引用；试剂危害查内置 GHS 词典，未收录的标「需人工核查」；检测原文是否报告了重复次数与误差 |
| 04 | 数据预期与论文专属图形 | 工艺流程图（工序 + 条件 + 设备来自原文）、界面结合机理图（由原文的处理方式与界面化学描述重建）、XRD（峰位取自原文）、FTIR（波数取自原文）、SEM 形貌对比（面板说明取自原文）。**原文没有的图不生成** |
| 05 | 结果分析与作图 | 折线 / 柱状 / 散点，数据来自原文的水平与最优值；原文未报告幅度时曲线只表示趋势；导出 SVG / PNG / CSV（Origin 可直接导入） |
| 06 | 实验指导书 | 试剂、配方、工序、仪器、标准、指标、参考文献全部来自原文；可打印、可导出 Markdown |
| 07 | 真实数据回填与矫正 | 比对表的指标 = 原文实际测量的指标；无最优值的显示「—」而非编造基准 |
| 08 | 论文撰写 | 研究背景与意义 / 研究空白 / 实验思路与方法 / 结果与分析 / 结论 / 未来方向，全部由抽取结果生成；参考文献 = 原文列表 |
| 09 | 语言处理 | 真实文本特征计算（句长变异系数、连接词密度、三段式结构度、TTR、平均句长）→ AI 痕迹得分；降 AI 改写为真实字符串变换并重新计分 |
| 10 | 论文评审 | 查重率与 AI 率（可解释算法）+ **对该论文全文的自动问题检测** + 三位专家（方向随论文领域变化） |

### 环节 10 的自动检测项
章节编号连续性 · 参考文献重复与字段完整性 · 指标是否都有结果分析 · 变量水平是否都有数据 ·
是否报告重复次数与误差 · 摘要与结论的名目一致性 · 标准引用完整性 · 仪器型号完整度。

## 4. 抽取质量的内置约束（防止误抽）

| 约束 | 作用 |
|---|---|
| 变量必须「名词 + **带单位**数值列表」且同句出现 | 排除页码、目录、化学计量比等数字 |
| 识别「分别提高了 35.19%」式幅度描述并剔除 | 它是结果，不是变量水平 |
| 「浓度分别为 0.5%／1.0%／1.5%」识别为水平枚举 | 不能与幅度混淆 |
| 剔除 `23 ℃ ± 5` 形式的公差 | 它是条件，不是水平 |
| 水平跨度 > 12 倍判为尺寸清单 | 排除「8 / 178 / 100 mm」类试件规格 |
| 温度阈值放宽到 2200 ℃ | 固溶 / 烧结可达 1200 ℃ 以上，不能按低温卡 |
| 指标去重（长名包含短名时保留长名） | 避免「厚度膨胀率」与「吸水厚度膨胀率」并存 |
| 原文最优值必须落在某变量水平集合内 | 否则判为误抽并丢弃 |
| 工序按真实工艺顺序重排 | 称量 → 配制 → 球磨 → 铺装 → 热压 → 冷压 → 烧结 → 养护 → 切割 |
| 剔除 Word 域代码行（PAGEREF / TOC / MERGEFORMAT） | 目录不会被当成正文 |
| 仪器可用「后缀 + 型号」启发式识别 | 覆盖各方向的非通用设备名 |
| 材料可用「名称（规格），购自厂家」通用写法识别 | 不依赖固定词表 |

## 5. 文件解析能力与边界（如实说明）

| 格式 | 状态 |
|---|---|
| **DOCX** | ✅ 浏览器内直接解析：ZIP 中央目录 + 解压 `word/document.xml`（纯 JS inflate，零依赖） |
| **TXT / MD / CSV** | ✅ 直接读取 |
| **粘贴正文** | ✅ 任何格式都可走这条路，**最可靠** |
| **PDF** | ✅ **v3 解析器**，见下表 |
| 扫描件 / 加密文档 | ❌ 无文字层时明确报错并给出替代方案，**不会用模板内容填空** |

### 5.1 PDF 解析器 v3（针对真实期刊 PDF 的四层修复）

用三篇真实期刊 PDF 逐环节复现问题后定位到的缺陷，全部已修：

| 层 | 旧行为 | 现在 |
|---|---|---|
| **过滤器链** | 只认 `FlateDecode`。遇到 `/Filter [ /ASCII85Decode /FlateDecode ]`（2000 年前后期刊常见）会把 ASCII85 压缩字节当正文读出 → **4017 个随机 ASCII 乱码** | 支持 `ASCII85 / ASCIIHex / Flate / LZW / RunLength` 按声明顺序串联解码，并支持 PNG Predictor 10–15；遇图像类过滤器跳过 |
| **zlib 头** | 只在首字节为 `0x78` 时剥离 2 字节头。QuarkXPress / Distiller 3 的老 PDF 用 **4KB 窗口（CMF=0x48）**，被漏判 → 整段 DEFLATE 从错误偏移解析 → 全部解压失败 | 按「CM=8 且 `(CMF<<8\|FLG) % 31 == 0`」判定，支持 FDICT 的 6 字节偏移，失败再退回 0 偏移 |
| **字体编码** | 只认 `/ToUnicode`。老 PDF **全篇没有 ToUnicode**，靠 `/Encoding 127 0 R` → `/Differences` 字形名，于是抽不出内容 | 新增约 200 个字形名→Unicode 表 + `StandardEncoding`(161–255) + `WinAnsi`(0x80–0x9F) + `MacRoman`(**完整 128 项**)；优先级：ToUnicode > Encoding 表 > ASCII 直通 > 双字节猜测 |
| **阅读顺序** | 按文件里对象的物理顺序拼接 → 标题被 Fig.4 图注顶掉、正文从中段开始 | 按页面树 `/Type /Pages → /Kids → /Page → /Contents` 还原（同页重复引用去重）；不足 240 字符才退回"散文度×长度"排序 |

**实测结果**：2000 *Nature*（Oxidants, oxidative stress and the biology of ageing）从 **4017 乱码 → 54,586 字符干净正文**，标题/摘要/关键词/参考文献全部正确；2001 *Trends in Microbiology*（biofilm resistance）抽出 26,572 字符；1954 *Nature*（cotton α-cellulose）确认为**扫描件无文字层**，给出明确的不可抽提示。

### 5.2 中文 / 英文抽取（不预设学科、不凭空生成）

- **短缩写整词匹配**：`SEM/TEM/BET/EIS` 原为大小写不敏感裸匹配，英文论文里 `assembly→SEM`、`system→TEM`、`between→BET`，**凭空多出 4 项表征手段**；已改为整词匹配。
- **品牌名词边界**：试剂商 `Acros` 会命中英文单词 `across`，把 "…vancomycin across the membrane…" 整句当成试剂清单；两个名单已全部加词边界。
- **作者姓氏护栏**：`system / setup / kit` 曾被当作设备线索，作者行会被当成仪器；现已收紧并加姓氏判定。
- **PDF 断行黏连修复**：`animalswith / thatthe / reviewreview / TRENDSin / compounds.A` 等黏连词会污染摘要、关键词与指标匹配，现有 5 条保守拆分规则（功能词白名单刻意排除 `and/then/one/are/our/can`，避免误伤 `understand / strengthen / microphone / nightmare / behaviour / hurricane`）。
- **行→段落合并**：两栏期刊正文行只有约 50 字符，"行"不能当"段落"；摘要推断改用合并后的段落。
- **题录来源全部标注**：标题 = `原文自带 / 正文识别 / 取自文件名`；摘要 = `原文自带 / 自动推断`；关键词 = `原文自带 / 自动归纳`。**原文没有的字段一律标注来源，绝不冒充原文内容。**
- **摘要候选**：原文无 `Abstract` 字段时返回前 6 段候选，界面上可「换一段」由你决定，而不是替他拍板。
- **参考文献**：支持"长块按编号炸开"（`…(1994).102.Seddon…` → 逐条）+ 文末编号式扫描 → 2000 *Nature* 从 **0 条 → 100 条**。

### 5.3 综述 / 展望类文献的处理

综述没有变量与实验步骤（**这是体裁使然，不是抽取失败**）。平台按**结构证据**判定类型（有无变量、工序、材料清单、方法学章节），再用标题 / 文件名 / 正文措辞佐证，然后自动切换为：

| 图 | 内容 | 数据来源 |
|---|---|---|
| **概念路线图** | 原文概念 → 类别，带频次 | 原文词频 |
| **概念对比矩阵** | 类别 × 概念 × 频次（分组条形 + 类别图例） | 原文词频 |
| **年份演进时间线** | 引用年份出现频次 | 原文年份统计 |

> **概念提取不预设任何学科词池。** 早期版本内置过一张"可穿戴传感"领域词表，套到生物膜论文上会出现「标志物: pH」「应用场景: stress」这类无意义归类 —— 这与"每篇论文都测同一套指标"是同一类错误，已全部移除。现在从**论文自身**提取：2–3 词术语短语（频次 ≥2）、高频长词（频次 ≥8，经通用学术停用词过滤）、中文 3–5 字片段（频次 ≥5）；并先剔除参考文献区、页眉页脚与引文行，避免 `Proc. Natl. Acad. Sci.`、`insightreview articles` 混进概念。
>
> 实测：2000 *Nature* → `oxidative stress×51 · life span×25 · stress resistance×13 · caloric restriction×9`；2001 *Trends* → `antimicrobial agents×19 · biofilm cells×13 · planktonic cells×6`。全部是该论文自己的术语。

## 6. 3D 科研绘图与 SCI 配图规范

### 6.1 三维图形（`figures3.js`，纯手写 SVG）
内置投影引擎（方位角 / 仰角 / painter 算法按深度排序），生成：

| 图 | 说明 | 数据来源 |
|---|---|---|
| **三维响应面** | 彩色网格曲面 + 等高底面网格 + 峰值标记 + 色标 | 由该论文的变量水平与最优值生成 |
| **三维柱状** | 变量水平 × 指标的三维柱体，含顶面/侧面明暗 | 同上 |
| **晶胞 / 球棍模型** | 晶胞棱（虚线）、a/b/c 坐标轴、原子按 CPK 配色、键、图例、Miller 晶面（可选） | 晶格参数从原文正则抽取；缺项则用通用占位并**在图上标注** |
| **层状 / 界面结构 3D** | 三维板层（顶面/前面/右面），层内按纤维 / 颗粒 / 网格纹理区分 | 由原文的材料与界面表述重建（检测到"纤维+基体"→ 纤维相/界面过渡区/基体相） |

### 6.2 期刊配色板（取自期刊制图惯例）
`Okabe–Ito`（色盲安全，Nature Methods 金标准，**投稿首选**）· `NPG / Nature` · `Lancet` · `NEJM` · `Science` · `GLM 莫兰迪`（低饱和，演示友好）。
图表风格切换即联动线宽、标记、网格与默认配色。

### 6.3 SCI 配图手册（图型 × 实验类型匹配）
按材料学科期刊惯例整理 10 类实验与图型/惯例的对应关系，并在界面中**按该论文的指标族自动匹配**。例如：

| 实验类型 | 推荐图型 | 制图惯例 |
|---|---|---|
| 力学性能 | 分组柱状 + 误差棒 / 应力–应变曲线 / 箱线图 / 三维柱状 | 必须报告 n ≥ 3 与误差棒；组间差异用显著性标记 |
| 工艺参数优化 | 折线（多水平）/ 三维响应面 + 等高线 / 主效应图 | 响应面是标配；峰位标最优条件 |
| 微观结构（SEM/TEM） | 多面板 A–D / 断面–表面成对 | **每个面板必须有比例尺、面板标号、放大倍数** |
| 物相与晶体结构 | XRD 谱 + 标准卡片线 / 特征峰局部放大 / 晶胞 3D | 标峰归属与 PDF 卡片号；给 a/b/c 与 α/β/γ |
| 化学组成与官能团 | FTIR 叠放 / XPS 分峰拟合 / 分子结构式 + 反应式 | XPS 须给分峰+拟合线+原始点；分子用骨架式 |
| 电化学 | 循环曲线 / 倍率柱状 / CV / EIS Nyquist + 等效电路 | 标电流密度与电压窗口；循环图常配库仑效率副轴 |

### 6.4 分子的 SCI 表达规范
界面内给出 5 种表达方式的**适用场合与理由**：

| 表达 | 用在什么时候 | 为什么 |
|---|---|---|
| **骨架式（键线式）** | 有机小分子、MOF 配体、钝化分子、偶联剂 —— **首选** | 省略 C 与 C–H，只标杂原子与官能团 |
| **球棍式** | 晶体结构、配位环境、吸附构型、界面结合 | 原子按 CPK 配色画球、键用圆柱，能表达立体构型 |
| **空间填充式** | 孔道占位、聚合物链段、大分子堆积 | 用范德华半径，说明"挤不挤" |
| **楔形/虚线式** | 手性中心（R/S） | 实楔朝观察者、虚线背离，只标关键手性中心 |
| **结构式** | 反应式与官能团转化（氧化/接枝/交联） | 只画参与反应的局部结构，条件写在箭头上下方 |

同时给出 **CPK 原子配色表**（C `#303030`、O `#E23B2E`、N `#2E5BE2`、Si `#C8A165`、S `#D9C22B`、P `#E8802A`、Cl `#3FBF3F`、Ti `#BFC2C7`…）与骨架式/球棍式/反应式的**示例绘制**，可直接导出。
