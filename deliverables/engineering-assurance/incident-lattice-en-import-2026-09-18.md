## 🏗️ 架构重构方案（Archi 交付）

> 完整版：`_dev/architecture/lattice-architecture-proposal.md`（v1.1，含实测标定）

### 核心结论
本次事故不是"一个 bug"，而是**管线没有层间契约**：L1（版面还原）产出 27,702 字符的残次品（空格率≈0），但 L1→L3→L5 之间没有任何质量闸门，垃圾被逐层放大成 14 个区块的噪声界面。**修 bug 必须配熔断器**，否则下次换个 PDF producer 还会复发。

### 分层设计（5 层，每层输出 `{data, quality, warnings}` 三段式契约）

```
L0 字节流/过滤器  →  L1 版面还原(空格+阅读顺序+换行)★事故点  →  L2 分词与句段
→  L3 字段抽取  →  L4 语言本地化★新增  →  L5 画像与呈现
```

- **L1**：空格必须在这里还原（kern 值/位移只存在于内容流，出了 L1 永久丢失）。现状 `walk()` 三个空白丢失通道：TJ 数组数字被当普通字符跳过、只认 `Td` 不认 `TD`/`Tm`、`Tw`/`Tc` 未读。
- **L3**：入口第一行检查 `quality==='hard-fail'` 直接短路——**下游有权拒绝上游**。
- **L4 本地化**：词典（`domain.js` 的 12 性能族中英词表 + 仪器/试剂/工序英文词表）+ 规则；查不到译名 → 原文 +「待译」标记，**绝不机翻乱编**。每项输出 `{ name(原文), zh, zhVia: glossary|rule|none, evidence }`。

### L1 失败契约（熔断表，防复发）

| 失败模式 | 检测信号 | 后果 |
|---|---|---|
| F1 文字层缺失（扫描件） | totalChars < 200 | 熔断于 L1 → 粘贴正文引导 |
| **F2 空格还原失败** | Latin 且 spaceRatio < 0.08 或 avgWordLen > 14 | **熔断于 L1**，禁止 L3 在黏连文本上运行（本次事故的放大器） |
| F3 换行还原失败 | lineCount/totalChars 异常低 | degraded，挂 layout-warning |
| F4 部分字体解码失败 | undecodedGlyphs > 5% | degraded，confidence 扣分 |
| F5 流解码失败 | decodedStreams < 50% | 熔断 |
| F6 阅读顺序无法确定 | 页面树遍历失败 | 回退散文度排序 + warning |

hard-fail ≠ 报错弹窗，而是"恢复卡 + 明确替代路径"；degraded 必须随数据流动，不得在任一环节被吞掉。

### 修复规则（ADR-001，阈值已实测标定）
- **R1 — TJ kern→空格**：`|kern|/1000×字号 ≥ 0.6×空格宽` → 插 1 空格；`≥1.6×空格宽` → 插 2。空格宽取 ① 简单字体 `/Widths[32]` ② Type0 `/W` ③ 回退 0.25em。交叉验证：195/1000×9.96pt≈1.94pt ≈ 空格宽；字距 10.2/1000×9.96≈0.10pt，正确连成 chemicals。CJK 字体默认不启用。
- **R2 — TD/Tm**：识别改为 `/(Td|TD|Tm)/`；ty≠0→换行、|tx|≥阈值→补空格；Tm 维护文本矩阵位置。
- **R3 — Tw/Tc**：读取状态备用（样本为 0，其它 producer 可能用 Tw）。
- L1 同时输出 spaceRatio / latinWordAvgLen / lineCount 质量指标。

### 界面信息架构重构（"一次只看一层"）
- **第 0 层 入口**（未载入时整屏只做一件事）：`从一篇文献开始` + 双卡「导入文献 / 先选研究方向」，材料方向从 10 卡片改为默认「自动识别」的下拉抽屉。
- **第 1 层 解析结果一句话**（永远可见）+ 唯一主按钮「下一步：研究定位 →」。
- **第 2 层 讲了什么**：标题（中/英）· 摘要（来源chip）· 关键词。
- **第 3 层 抽到了什么**：折叠为一条概览「原料5·仪器4·变量3·指标6」，点击展开手风琴（每次只开一块）。
- **第 4 层 解析诊断**：默认折叠，有 warning 才自动展开。
- **导航**：左栏从"10 项清单"改为"3 阶段工作台"（沿用现有 PHASES），未解锁环节显示为灰色 ghost 项；「运行整条流水线」主按钮降级为次级。
- **动效**（全部沿用现有令牌）：卡片 hover `translateY(-1px)` 140ms、按下 scale(.995) 90ms、层级进入 translateY(8px)+淡入 240ms、手风琴 0fr→1fr 240ms、指针跟随径向高光（rAF 节流 + `pointer:fine` + `prefers-reduced-motion` 降级）。性能红线：只碰 transform/opacity、单帧动画节点 <200。

### ADR（6 条）
1. 空格还原放 L1（版面还原）而非 L2 词典切分 —— 位置信息只在 L1，词典切分错误率高（"therapist"→"the rapist"类）。
2. 翻译层做纯前端（词典+规则）+ 可选外部端点做摘要机翻降级，不引入后端。
3. 10 环节不砍，改为"渐进式工作台"呈现（赛事叙事保留，重构限于视图层）。
4. 信息密度策略：默认低密度，密度权力交给用户（compact 档保留 14 块供专家复核）。
5. CSS 动效性能边界：只碰 transform/opacity、指针特效 rAF+pointer:fine、无动画库、无 canvas 粒子。
6. **层间熔断契约**：`{data,quality,warnings}` + L1/L3 两处硬熔断 + 熔断事件写 RUN LOG —— 防复发的架构级保险，与回归语料互补（测试防已知，熔断兜未知）。

### 实施顺序
① L1 空格还原（R1/R2）+ spaceRatio 熔断 → ② L3 confidence 熔断 → imp 恢复卡 → ③ TERM_MAP 对齐 + L4 模块 + 视图只读 profile → ④ imp 视图四层重构 → ⑤ 动效落地。

## 📝 呈现与中文化规范（Docu 交付）

**严重度定义**：P0＝误导用户/摧毁信任；P1＝看不懂（术语无解释、英文原样、状态不明）；P2＝杂乱（信息一次抛出过多）。

### 关键文案问题（P0 级，直接影响信任）

1. **虚构 LLM 外观**（index.html:85）：顶栏写「模型 LATTICE-Sci-1 · 温度 0.2」，平台实为本地规则引擎。→ 改「本地规则引擎 · 每一步计算都可点开查看依据」。
2. **`runStage` 静默置 done**（app.js:386）：会把之前所有未完成环节标为 done，环节状态瞬间从"未做"变"已完成"，用户对状态彻底失去信任（"很多东西都是错误的"的佐证）。→ 不静默置 done，跳过的标「已跳过（未运行），结果为占位，点此补运行」。
3. **"站内命中的真实文献"没命中也硬塞 6 条**（views2-stages.js:587-597）：未命中时静默退回 `lib.rows.slice(0,6)`，面板标题却写"命中"——**实打实的误导性呈现**。→ 无命中时明示"本地库无相关文献，可点上方链接到 OpenAlex/知网"，绝不凑数。
4. **"未报告"混淆两种完全不同的情况**：(a) 原文真的没写；(b) 解析器没抽出来（本次事故）。→ 拆成「原文未写明」（灰，hover 说明原文确实没有）与「未能读出」（黄，hover 引导改用粘贴正文）。
5. **"查重率"易被当知网口径**（views2-paper.js:269）：→ 改「与引用文献的表述重合度」，并注明"不等于知网/万方查重率，仅供自查"。
