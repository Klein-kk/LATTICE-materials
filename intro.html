§1 · CORE

不只是 PDF 阅读器，
是从文献到机制图的流水线

六条核心能力，覆盖你写论文 / 做综述 / 设计实验时需要的全部工具。

01

10 阶段自动流水线

从 imp（灵感）→ scope（选题）→ design（设计）→ analysis（分析）→ review（校对），覆盖材料学科研的完整闭环。

02

分子级 3D 可视化

论文里"甘氨酸-甘氨酸氢键"不再是文字描述。three.js 驱动的查看器，原子、键、作用力都在浏览器里可旋转。

03

本地优先 · 云端可选

论文永远先存本机；登录后才同步到云端，由 Supabase 行级安全策略（RLS）隔离，配置全程开源可审计。

04

桌面助手「小晶」

可拖拽的悬浮答疑助手。基于当前阶段上下文，给出"接下来该做什么"的指南和检索方向。

05

不是"AI 生成内容"。骨架 / 措辞 / 引用格式全部遵循 Nature / Elsevier / IEEE 模板，引用真伪可追溯。

06

中英双语 · 主题切换

界面术语、菜单、提示文案全程中英对应；明 / 暗主题适配，状态持久化在本地。

§4 · FAQ

常见问题

关于登录、安全、离线使用和数据归属——一次说清楚。

可以。LATTICE 默认是本地模式——所有论文都存在你浏览器的 localStorage，刷新不丢。换设备、换浏览器、清缓存会丢，但不会上传到任何服务器。登录只是解锁多设备同步和云端备份。
登录后你写入的每篇论文，会作为一行记录写入 Supabase 表 papers(user_id, id, name, ...)。表上启用了行级安全策略（RLS），数据库层面就保证只有你自己能读你自己的行，平台运营方也读不到你的论文原文。
因为 Google Cloud 在部分高校 / 院所账号下被禁用。Supabase 注册流程不依赖 Google 账号，且 RLS 策略用 PostgresSQL 写，透明、可复现审查。
我们使用 three.js 渲染原子（球·按元素着色）和键（圆柱·按阶数变粗）。氢键 / 范德华力等非共价作用力用虚线圆柱 + 渐变发光材质表示，距离和方向遵守真实分子几何（O-H···O 接近 1.8 Å）。详细参数见 assets/js/viewer-forces.js。
在。云端数据走 Supabase。你在任一浏览器登录后，平台会拉取该账号下所有论文元数据到本机（论文正文按需拉取，本地保留副本以便离线工作）。
LATTICE 平台本身和本页功能完全免费。云端 Supabase 用免费档（500 MB / 50k 行），个人使用足够。
